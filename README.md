# حلبة 310 (run3d)

لعبة سباق هايبركار ثلاثية الأبعاد تشتغل في المتصفح بدون تثبيت. مكتوبة بـ JavaScript و three.js.

## الأوضاع

| الوضع | الوصف |
|---|---|
| ضد الكمبيوتر | سباق مع 5 منافسين، وبيشتغل بدون إنترنت. المستوى: سهل / متوسط / صعب. |
| لاعبين على جهاز واحد | شاشة منقسمة وكيبورد واحد. ممكن تضيف منافسين كمبيوتر (0 / 2 / 4). |
| أونلاين | واحد يعمل غرفة ويبعت الرمز لأصحابه (لحد 6 لاعبين). |

كل لاعب بيكتب اسمه قبل ما يبدأ، والاسم بيظهر في ترتيب السباق والنتيجة.

## المضامير

الكلاسيك (2.8 كم)، السوبر أوفال (2.4 كم)، غابة التواء (2.6 كم)، الصحراء العملاقة (3.8 كم).
قبل السباق بتختار نوع العربية (فانتوم GT، سبرينت، تيتان، فلاش) والسائق (6 شخصيات) والمضمار، وكمان في الأونلاين جوّه الغرفة.

كل مضمار له خط بداية ونهاية وإشارة انطلاق ومدرجات. وفي الأونلاين المضيف هو اللي بيختار المضمار وعدد اللفات.

## التحكم

| | لاعب 1 / لاعب واحد | لاعب 2 (جهاز واحد) |
|---|---|---|
| القيادة | الأسهم أو `W A S D` | الأسهم |
| نيترو | `Shift` | `Shift` اليمين |
| فرامل يد | `Space` | `Enter` |
| الرجوع للمسار | `R` | `T` |

في وضع اللاعبين على جهاز واحد: اللاعب الأول بـ `W A S D` واللاعب الثاني بالأسهم.
وللكل: `C` تغيير الكاميرا، `P` إيقاف مؤقت، `M` كتم الصوت. وعلى الموبايل فيه أزرار على الشاشة.

## التشغيل

اللعبة ملف واحد `index.html` ومعاه مجلد `vendor/` فيه المكتبات، فتشتغل بدون إنترنت.

```bash
python3 -m http.server 8080     # وبعدين افتح http://localhost:8080
```

## النشر على GitHub Pages (مطلوب للأونلاين بين الأجهزة)

1. من إعدادات المستودع: `Settings` ثم `Pages`.
2. في `Source` اختار `Deploy from a branch`، والفرع `main` والمجلد `/ (root)`.
3. بعد دقيقة هيظهر الرابط. ابعته لأصحابك.

## الأونلاين

- الاتصال مباشر بين اللاعبين (WebRTC) عن طريق [PeerJS](https://peerjs.com). الرمز عبارة عن 5 حروف بيتولد عند إنشاء الغرفة.
- محتاج إن الصفحة تتفتح من استضافة عادية (https). لو الإنترنت أو PeerJS مش متاح، الغرفة بتشتغل بين تابات نفس المتصفح بس، وبتظهر رسالة بتوضح ده.
- كل لاعب بيحسب عربيته عنده وبيبعت مكانها للباقي حوالي 20 مرة في الثانية. المضيف بيوزع الحالة على الكل.
- في شبكات بتمنع الاتصال المباشر (بدون خادم TURN) وممكن اللاعبين ميعرفوش يتصلوا ببعض.

## التطوير

```bash
npm install
npm run build    # بيولّد index.html من مجلد src
npm test         # بيجرب المضامير بالمحاكاة (طول المضمار، أقل نصف قطر، سباق للـ AI)
```

| الملف | الوظيفة |
|---|---|
| `src/sim.js` | فيزياء العربية والتصادم وسائق الكمبيوتر |
| `src/tracks.js` | تعريف المضامير (نقاط المنحنى ونقطة البداية) |
| `src/world.js` | المشهد: سماء، مضمار، حواجز، مدرجات، أشجار، ثيمات المضامير |
| `src/car.js` | موديل العربية (تصميم أصلي بدون شعارات) |
| `src/fx.js` | دخان وشرر وصوت المحرك |
| `src/net.js` | الغرف والاتصال (PeerJS مع بديل BroadcastChannel) |
| `src/game.js` | القوائم، الأوضاع، الشاشة المنقسمة، الواجهة، حلقة اللعب |
| `src/template.html` | الصفحة والتنسيق |

لإضافة مضمار جديد ضيف عنصر في `src/tracks.js` (نقاط `pts` مرتبة في حلقة مقفولة، و`start` قريب من خط مستقيم طويل)، وشغّل `npm test` عشان تتأكد إنه ما فيهوش خبطات.
